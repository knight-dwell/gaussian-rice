Terminal greeter library: one random entry is shown in every new terminal.

Each .txt file here is a collection. Entries are separated by a line with a
single "%" (the classic `fortune` format).
  * quotes / funny: the text, then a last line starting with "— " = who said it
  * stories: a first line starting with "## " = title, then a short paragraph

Add your own files or entries; every *.txt file in this folder is used
(this README is skipped). Keep entries short: they are wrapped to fit.
